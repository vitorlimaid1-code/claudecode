    Como usar

    1. Dados do livro: preencha título, autor, ficha/créditos e escolha quais páginas iniciais incluir (folha de rosto, dedicatória, sumário…).
    2. Capítulos: clique em ＋ para criar, arraste para reordenar e clique para editar. Desmarque “Numerado” para seções como Prefácio ou Agradecimentos.
    3. Texto: escreva, cole ou use Importar texto (Word .docx, .txt ou .md). Títulos do Word (Título 1) viram capítulos automaticamente.
    4. Diagramação: formato da página, margens, fontes, entrelinha, cabeçalhos e numeração. Experimente os estilos prontos.
    5. Exportar PDF: gera o miolo pronto para gráfica ou impressão sob demanda (KDP, Clube de Autores, UICLAP…).

    Tudo é processado e salvo no seu computador. Os projetos são arquivos .livro; há também salvamento automático de recuperação.
